
Shopbop is my e-commerce web app built with Laravel. It has two panels: a **customer panel** where people can browse products, leave reviews, and manage their accounts, and an **admin panel** where I can manage products, orders, and site content. It’s fully responsive and secure, with user authentication, image management, and Google reCAPTCHA for contact forms.

## Built using 
- Laravel, Livewire, Bootstrap and Sql

## Features

- Customers can browse products, leave reviews, and manage their accounts.  
- Admins can add/edit products, manage orders, and handle site content.  
- Secure login with role-based access.  
- Product images are handled using Laravel’s storage system.  
- Google reCAPTCHA is used for forms to prevent spam.  
- Responsive design with frontend assets built using Vite.
